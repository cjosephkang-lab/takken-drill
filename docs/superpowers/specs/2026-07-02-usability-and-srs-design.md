# 使いやすさ改善 + 学習効率エンジン 設計メモ（2026-07-02）

## 目的

1. スマホでの操作コスト（スクロール・タップ）を下げる。
2. 「絶対合格」に向けて、学習科学の定番手法（間隔反復・想起練習）で学習効率を最大化する。

## 使いやすさ（ユーザー選択済み: スクロール削減 / 固定ナビ / 続きから再開）

- **合格作戦ボードの折りたたみ**：統計タイル（回答済み・習得済み・今日）とボードを1セクションに統合。閉じた状態でも「想定◯点・あと◯点」をヘッダー行に常時表示。デフォルト閉。
- **固定ナビ**：画面下に「前へ／次へ」の固定バー（`env(safe-area-inset-bottom)` 対応、`viewport-fit=cover` を追加）。「前へ」機能を新設。
- **続きから再開**：`takken-drill.settings.v1` に 年度/分野/状態フィルタ・おすすめ順・ボード開閉を保存し起動時に復元。現在の問題は従来通り progress に保存。
- 「初期化」ボタンの移動はユーザー判断で見送り。

## 学習効率エンジン

- **AnswerRecord 拡張**（後方互換・読み込み時に旧レコードを補完）：`streak`（連続正解）/ `attempts` / `lapses` / `nextReviewAt`。
- **復習間隔**：不正解→1日、連続1回→2日、2回→7日、3回→14日、4回以上→30日。`nextReviewAt` が現在時刻を過ぎたら「復習期限」。
- **習得判定**：`streak >= 2` で「習得済み」。ボードに全体・科目別の習得数を表示。
- **想起練習**：画面に出す回答状態はセッション内（`sessionAnswers`）のみ。再訪・再起動時は前回の答えを見せず解き直し。同一セッション内の再回答はロック（成績の水増し防止）。再訪時は「挑戦◯回目・前回正解/不正解」を表示。
- **出題優先度（おすすめ順モードの「次へ」）**：復習期限 → 未回答 → 通常順。フィルタ・ステータスショートカット・ヘッダーに「復習 N」を追加。
