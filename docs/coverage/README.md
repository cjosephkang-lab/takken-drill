# 過去問の網羅率の調査データ（2026-10-19）

2011〜2025年の17回分と令和8年の全3,556選択肢に、AIが論点を付け（`tags/`）、同じ規則を指すものを1,833の規則クラスターに束ねた（`clusters/`）。調査の結論は [../retrospective/2026-10-18-r8-honshiken.md](../retrospective/2026-10-18-r8-honshiken.md) の「過去問の網羅率の調査」。

- `tags/<試験>.jsonl`: 1選択肢1行。exam, q, item（1〜4 / ア〜エ）, field（分野）, major（大論点。`taxonomy.md` の固定リスト）, key（論点キー＝正しい規則の要点をAIが書いたもの）, truth（その選択肢が正しいか）。
- `clusters/<分野の区分>.jsonl`: id（`<試験>-<問2桁>-<肢>`）→ cluster（規則の代表文）。
- `compute_coverage.py`: 網羅率の計算。このフォルダで `python3 compute_coverage.py` を実行する。
- `taxonomy.md`: 大論点の一覧と論点キーの書き方。

問題文そのもの（宅建レトスから取得した本文）は含めていない。論点キーと規則文はAIの言い換えで、人は全件を確かめていない。法改正で今の法律と合わない規則も、出題当時の内容のまま含まれる。
