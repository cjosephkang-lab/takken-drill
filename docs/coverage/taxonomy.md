# 細かい論点（論点キー）の書き方

その選択肢の正誤を決めている「規則」を、次の形で1行に書く。

`<制度・場面>：<規則の要点>`

- 例: `相続人の範囲：配偶者の連れ子は養子縁組がなければ相続人でない`
- 例: `営業保証金：本店移転で保管替えを請求するとき費用を予納する`
- 例: `クーリング・オフ：売主が宅建業者でなければ適用されない`
- 例: `法定地上権：1番抵当権設定時に土地と建物の所有者が同一でなければ成立しない`

規則は正しい内容で書く（選択肢が誤りの場合も、誤りの内容ではなく正しい規則を書く）。数字・主体・対象の範囲・例外など、正誤を分けた要素が分かるように書く。計算問題は `相続分の計算：代襲相続人は被代襲者の相続分を頭数で分ける` のように、使った規則を書く。統計の選択肢は `統計：<統計名>の<項目>` で書く（数値は書かない）。
