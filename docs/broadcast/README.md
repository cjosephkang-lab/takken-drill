# 発信の方針（broadcast）

宅建の学習過程を録画し、合格発表のタイミングで発信するための方針を置く場所。
調べた事実と、その出典を残す。

## なぜこのフォルダがあるか

きじーさん（カメラマン）との打ち合わせ（2026-09-09）で「発信は合格してから。
過程の動画は残しつつ、合否が出るタイミングで一気に出す」という助言を受けた。
つまり**いま必要なのは公開ではなく、過程を欠けさせずに溜めること**。

映像は後から作れない。だからテキストの学習ログを自動化したのと同じ理屈で、
撮り方と出し方を先に決めておく。

## 中身

| ファイル | 中身 |
|---|---|
| `2026-09-09-recording-and-posting.md` | 録画の手順・著作権の制約・出し先と尺・法規制の当てはめ |

## 読み方

**これは仮説を含む発信案であって、法的に確認済みの方針ではない。**
初稿は法的安全性・SNSアルゴリズム・BtoB信頼獲得の3つを、都合のよい一つの成功
物語へ接続しすぎており、codexの敵対レビューで4箇所を修正した（該当箇所に経緯を
残してある）。投稿前に、著作権については弁護士に確認する価値がある。

**事実と推測を明示的に区別してある。** 出典URLの無い主張は書かない方針だが、
出典があっても一次情報でないもの・古いデータのものは、その旨を本文に書いている。

特に末尾の「確信度が低い点」は必ず読むこと。実証データが無いまま推論で
組み立てた箇所が明示してある。
