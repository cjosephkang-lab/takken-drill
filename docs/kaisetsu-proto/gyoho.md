# r6-27 営業保証金（令和6年 問27）正解 4

前提: Aは保証協会の社員ではない（社員なら営業保証金を供託しなくてよい。法64条の13）。

## 肢1 ×

**0. 判定と決め手**　金銭だけで供託しているなら、新たに供託するのではなく、今の供託所に「保管替え」を請求する（法29条1項）。新たに供託するのは、有価証券を含むとき。

**1. 規則の全体（法29条1項）**

| 要素 | 内容 |
|---|---|
| きっかけ | **主たる事務所**を移したため、最寄りの供託所が変わった |
| 分かれ目 | 金銭**のみ** → 保管替えを請求する／それ以外（有価証券のみ、金銭と有価証券の両方）→ 移転後の最寄りの供託所に新たに供託する |
| 保管替えの請求先 | **今供託している（移転前の）供託所** |
| 期限 | どちらも「遅滞なく」 |
| 費用 | 保管替えは費用を前払いする（予納） |
| 済んだ後 | 遅滞なく、供託書正本の写しを付けて免許権者に届け出る（規則15条の4） |
| 古い供託所の分 | 新たに供託したときは、移転前の供託所の分を**公告なし**で取り戻せる（法30条1項後段・2項かっこ書） |

**2. 境界**
- 支店（従たる事務所）を移しても、この規定は働かない。供託所は主たる事務所で決まる（法25条1項）。
- 「金銭と有価証券の両方」は「金銭のみ」に当たらないので、新たに供託する。
- 「保管替え」と「差し替え（変換）」は別物。差し替えは、有価証券の償還などで供託する物を入れ替えること（規則15条の4の2、解釈運用25条4項関係）。

**3. 次に変えられやすい箇所**
- (a) 分かれ目を逆にする:「有価証券を含むなら保管替え」→×（法29条1項）。実績 2016-40-1、2017-32-1、2020-12-33-2
- (c) 請求先を変える:「移転後の供託所に保管替えを請求」→×。請求先は今供託している供託所（法29条1項）
- (c) 期限を変える:「2週間以内」→×。法29条は「遅滞なく」。2週間は不足額の供託（法28条1項）の数字
- (c) 後始末:「移転前の分を取り戻すには6か月以上の公告が必要」→×（法30条2項かっこ書）。実績 2016-40-4

**4. 趣旨**　営業保証金を常に「本店の最寄りの供託所」に置いておくための規定。金銭なら供託所の間で移せば済むので、二重に供託させない。

**5. ○×**
1. 有価証券だけで供託している業者が主たる事務所を移し、最寄りの供託所が変わった。遅滞なく保管替えを請求しなければならない。→ **×**（保管替えは金銭のみのとき。法29条1項）
2. 金銭だけで供託している業者は、移転後の主たる事務所の最寄りの供託所に保管替えを請求する。→ **×**（請求先は今供託している供託所。法29条1項）
3. 有価証券を含むため新たに供託した業者は、移転前の供託所の営業保証金を、公告をしないで取り戻せる。→ **○**（法30条1項後段・2項かっこ書）

## 肢2 ×

**0. 判定と決め手**　還付を受けられるのは「宅建業に関し取引をした者」が「その取引により生じた債権」を持つ場合だけ（法27条1項）。従業員の交通事故による損害賠償請求権は、取引から生じた債権ではない。

**1. 規則の全体（法27条1項ほか）**

| 要素 | 内容 |
|---|---|
| 還付を受けられる人 | 業者と宅建業に関し取引をした者。**宅建業者は除く** |
| 対象の債権 | **その取引により生じた**債権 |
| 限度 | その業者が供託した営業保証金の全額（本店1,000万円＋支店1か所ごとに500万円。令2条の4）。支店で取引した人も全額の範囲で受けられる |
| 手続き | 先に国交大臣から「取引の時に宅建業者でなかった」ことの確認書をもらう（保証金規則1条） |
| 後始末 | 不足が出たら、業者は通知書を受け取った日から2週間以内に不足額を供託し（法28条1項、保証金規則5条）、供託してから2週間以内に届け出る（法28条2項） |

**2. 境界**
- 対象外: 取引から生じたのではない債権（交通事故など）。宅建業ではない取引の債権（建物の建築請負の代金 2020-10-35-1、家賃の収納代行 2018-43-2）
- 取引の相手が宅建業者なら還付を受けられない（法27条1項かっこ書。平成29年4月1日施行の改正で加わった。保証金規則附則で施行日を確認）

**3. 次に変えられやすい箇所**
- (a) 人を変える:「相手方が宅建業者でも還付を受けられる」→×（法27条1項かっこ書）。実績 2021-10-34-2
- (a) 限度を変える:「支店で取引した人は支店の500万円まで」→×（全額）。実績 2016-40-3、2025-35-4
- (c) 不足額の期限:「還付の日から2週間」→×。「通知書を受け取った日から2週間」（法28条1項、保証金規則5条）。届出は「供託した日から2週間以内」（法28条2項）。実績 2016-40-2、2023-30-ウ

**4. 趣旨**　営業保証金は、宅建業の取引で損をした客（主に一般の人）のための担保。取引と関係ない損害や、プロの業者同士の損害までは守らない。

**5. ○×**
1. 宅建業者Bが宅建業者Aから宅地を買い、Aの債務不履行で損害賠償請求権を得た。BはAの営業保証金から還付を受けられる。→ **×**（業者は除かれる。法27条1項かっこ書）
2. Aと建物の建築請負契約を結んだ建設業者は、請負代金について営業保証金から還付を受けられる。→ **×**（宅建業の取引ではない。法27条1項、実績 2020-10-35-1）
3. 還付で営業保証金が足りなくなった。Aは、免許権者からの通知書を受け取った日から2週間以内に不足額を供託しなければならない。→ **○**（法28条1項、保証金規則5条）

## 肢3 ×

**0. 判定と決め手**　有価証券の評価は、国債が額面どおり（100%）、地方債が90%、その他の債券が80%（規則15条1項）。肢は数字を1段ずつずらしている。前半の「金銭と有価証券の両方で供託できる」は正しい（法25条3項）。

**1. 規則の全体（法25条3項、規則15条・15条の2）**

| 要素 | 内容 |
|---|---|
| 使えるもの | 金銭。または、国債証券・地方債証券・国交大臣が指定した社債券などの債券（規則15条の2）。両方を合わせてもよい |
| 評価 | 国債＝額面どおり／地方債・**政府保証債**＝額面の90%／その他の債券＝額面の80%（規則15条1項1〜3号） |
| 同じ規則が使われる場面 | 支店を新しく出したとき（法26条2項）・不足額を供託するとき（法28条3項）・主たる事務所を移して新たに供託するとき（法29条2項）・弁済業務保証金（法64条の7第3項）。どこでも同じ評価になる |

**2. 境界**
- 列挙されているのは債券だけ。株式は入っていない（規則15条の2）。
- 時効が近い債券、解散中の法人（特別清算中を除く）が出した債券は「好ましくない」とされ、分かったら速やかに差し替える（解釈運用25条3項関係）。

**3. 次に変えられやすい箇所**
- (e) 3段の数字を入れ替える。毎回この形で出ている。実績 2012-33-1、2018-43-4、2021-10-34-4、本肢
- (a) 両方で供託できるかを変える:「支店を新しく出した分は金銭で供託しなければならない」→×（法26条2項が法25条3項を使う）。実績 2021-10-34-3、2025-35-2
- (a) 政府保証債を「その他の債券（80%）」に入れる→×。地方債と同じ90%（規則15条1項2号）
- 計算させる形（下の○×3）

**4. 趣旨**　お金に換える時に値下がりするおそれの大きさに合わせて割り引く。国債がいちばん確かなので額面どおり。

**5. ○×**
1. 政府が債務を保証した債券は、額面の100分の80で評価される。→ **×**（90%。規則15条1項2号）
2. 事業を始めた後に支店を出した場合、その支店の分の営業保証金は金銭で供託しなければならない。→ **×**（法26条2項→法25条3項）
3. 本店と支店1か所の業者が、額面1,500万円の地方債証券だけで営業保証金を供託した。これでは足りない。→ **○**（必要な額＝1,000万＋500万＝1,500万円。評価＝1,500万×90/100＝1,350万円で、150万円足りない。令2条の4、規則15条1項2号。計算は python で確認）

## 肢4 ○

**0. 判定と決め手**　支店をどこの県に出しても、営業保証金は**主たる事務所**の最寄りの供託所に供託する（法26条2項が法25条1項を使う）。

**1. 規則の全体（法26条）**

| 要素 | 内容 |
|---|---|
| 主体 | 事業を始めた後に事務所を新しく出した業者（免許換えで事務所が増えた場合も含む。法26条1項かっこ書） |
| 額 | 新しい事務所1か所ごとに500万円（令2条の4） |
| 供託先 | 主たる事務所の最寄りの供託所（法26条2項→25条1項） |
| 使えるもの | 金銭・有価証券。両方でもよい（→25条3項） |
| 届出 | 供託書の写しを付けて免許権者に届け出る（→25条4項） |
| 業務を始められる時 | **届け出た後**でなければ、新しい事務所で事業を始められない（→25条5項） |

**2. 境界**
- 「事務所」に当たるのは、本店・支店などと、契約を結ぶ権限のある使用人を置く継続的な施設（令1条の2）。宅建業を営まない支店は事務所ではない（解釈運用3条1項関係）。案内所も事務所ではない。どちらも営業保証金を増やす必要はない。
- 甲県知事免許の業者が乙県に支店を出すと、免許換え（大臣免許）も必要になる（法7条1項3号）。営業保証金とは別の手続き。
- 免許をもらってから3か月で催告、その後1か月で取消しができるという規定（法25条6項・7項）は、最初の免許の時の規定。法26条2項はこれを使っていない（条文で確認）。

**3. 次に変えられやすい箇所**
- (a) 供託先:「新しい事務所の最寄りの供託所」→×（→25条1項）。実績 2012-33-2、2014-29-3、2017-39-ア、2020-12-33-1、2025-35-3
- (c) 順番:「供託すれば、届け出る前でも新しい事務所で業務を始められる」→×（→25条5項）。実績 2011-30-1、2020-10-35-2
- (a) 額: 支店は500万円（本店の1,000万円と取り違えさせる）。実績 2012-33-3、2020-10-35-4

**4. 趣旨**　どの事務所で取引した客も、1か所の供託所で全額の範囲から還付を受けられるようにする（肢2の「全額が限度」とつながる）。

**5. ○×**
1. 支店を新しく出した業者は、その分を供託して届け出た後でなければ、その支店で事業を始めてはならない。→ **○**（法26条2項→25条4項・5項）
2. 甲県知事免許の業者が乙県に支店を出したときは、乙県の支店の最寄りの供託所に500万円を供託する。→ **×**（主たる事務所の最寄り。→25条1項）
3. 宅建業を営まない支店を新しく出した場合も、500万円を追加で供託しなければならない。→ **×**（事務所に当たらない。令1条の2、解釈運用3条1項関係）

# r5-32 業者が行う届出（令和5年 問32）正解 4（誤っているもの）

## 肢1 ○

**0. 判定と決め手**　事務所の名称と所在地は免許申請書に書く事項（法4条1項4号）。変わったら30日以内に免許権者に変更を届け出る（法9条1項）。甲県の中なので免許換えは要らず、届出先は甲県知事。

**1. 規則の全体（法9条1項・4条1項）**

| 要素 | 内容 |
|---|---|
| 届出が要る事項 | 法4条1項1〜5号: ①商号・名称 ②法人の役員と政令で定める使用人の氏名 ③個人の氏名と政令で定める使用人の氏名 ④事務所の名称・所在地 ⑤事務所ごとの専任宅建士の氏名 |
| 届出が要らない事項 | 6号「ほかに営んでいる事業の種類」（兼業） |
| 期限・届出先 | 30日以内に、免許をくれた大臣または知事へ |
| 一緒にやること | 免許証に書いてある事項が変わったら、免許証の書換えも申請する（規則4条の2） |

**2. 境界**
- 他の県に支店を出したら、変更の届出ではなく免許換え（知事免許→大臣免許。法7条1項3号）。同じ県の中で増やすだけなら免許換えは要らない（実績 2020-10-26-4）。
- 宅建業を営まない支店は「事務所」に当たらない（解釈運用3条1項関係）ので、4号の届出事項にもならない。
- 役員は「氏名」だけが届出事項。住所は入らない（法4条1項2号。実績 2020-12-31-4）。

**3. 次に変えられやすい箇所**
- (c) 期限:「2週間以内」「遅滞なく」→×。30日以内（法9条1項）
- (a) 事項:「兼業の種類が変わったら届け出る」→×（6号は法9条1項の対象外）。実績 2017-36-3
- (a) 事項:「非常勤の役員なら届出は要らない」→×。法4条1項2号は常勤に限っていない。実績 2018-36-4
- (a) 境界:「乙県に支店を出したら甲県知事に変更を届け出る」→×（免許換え。法7条1項3号）

**4. 趣旨**　免許をくれた役所が「誰が、どこで」営業しているかを常に正しくつかみ、名簿を公衆が見られるようにしておく（法8条・10条）。

**5. ○×**
1. 法人の業者が非常勤の取締役を新しく選んだ。30日以内に免許権者に届け出なければならない。→ **○**（法9条1項・4条1項2号）
2. 業者が新しく建設業を始めた。30日以内にその旨を免許権者に届け出なければならない。→ **×**（兼業は法4条1項6号。法9条1項の対象外）
3. 甲県知事免許の業者が乙県に宅建業を営む支店を出して営業を続ける場合、30日以内に甲県知事に変更を届け出れば足りる。→ **×**（大臣免許への免許換え。法7条1項3号）

## 肢2 ○

**0. 判定と決め手**　合併で消えた法人については、**消えた法人の代表役員だった者**が、合併の日から30日以内に免許権者に届け出る（法11条1項2号）。合併の相手が業者でないことは関係ない。

**1. 規則の全体（法11条）**

| 場合 | 届け出る人 | 30日を数え始める日 | 免許がなくなる時 |
|---|---|---|---|
| 死亡 | 相続人 | 死亡を**知った日** | 下の注 |
| 合併で消滅 | 消えた法人の代表役員だった者 | その日 | 下の注 |
| 破産手続開始の決定 | **破産管財人** | その日 | **届け出た時**（11条2項） |
| 合併・破産以外の解散 | **清算人** | その日 | 届け出た時 |
| 廃業 | 個人本人／法人の代表役員 | その日 | 届け出た時 |

届出先はどれも、免許をくれた大臣または知事。
注: 法11条2項（届け出た時になくなる）は3〜5号だけが対象。死亡と合併の場合にいつなくなるかは条文に書いていない（死亡の時になくなるとして出題された例: 2017-44-3。公式の根拠は**未確認**）。

**2. 境界**
- 残った会社（存続会社）が、消えた会社の免許を引き継ぐことはない（引き継ぐ規定がない。実績 2017-44-1、2020-10-26-1）。
- ただし、消えた業者が結んでいた契約の取引を終わらせる範囲では、一般承継人（存続会社）が業者とみなされる（法76条）。

**3. 次に変えられやすい箇所**
- (a) 届け出る人:「存続会社の代表役員が届け出る」→×（法11条1項2号）。実績 2012-27-4
- (a) 数え始める日: 「知った日から」は死亡だけ（法11条1項柱書かっこ書）。実績 2012-27-1、2021-12-29-3
- (a) 届け出る人: 破産なら破産管財人、解散なら清算人。本人や代表者ではない。実績 2016-35-3、2021-12-36-1、2014-27-3、2025-41-2
- (d) なくなる時:「破産手続開始の決定の時に免許がなくなる」→×。届け出た時（法11条2項）。実績 2020-10-43-3

**4. 趣旨**　業者がいなくなった事実を、それをいちばんよく知っている人に届けさせ、名簿と免許を実際に合わせる。

**5. ○×**
1. 法人業者C（乙県知事免許）が破産手続開始の決定を受けた。Cの代表役員が30日以内に乙県知事に届け出なければならない。→ **×**（破産管財人。法11条1項3号）
2. 個人業者が死亡した。相続人は、死亡した日から30日以内に届け出なければならない。→ **×**（死亡を知った日から。法11条1項柱書）
3. 業者Bが合併で消えた。存続会社は、Bが結んでいた契約の取引を終わらせる範囲で、宅建業者とみなされる。→ **○**（法76条）

## 肢3 ○

# r4-38 クーリング・オフ（令和4年 問38）正解 4

前提: 業者が自ら売主の宅地の売買で、買受けの申込みは**喫茶店**でした（事務所等以外の場所）。

この問題の○×では、特に書かない限り、買主は業者ではなく、書面で告げられた日から8日以内で、引渡しと代金全部の支払いはまだ両方そろっていないものとする。

## 肢1 ×

**0. 判定と決め手**　できなくなるのは「引渡しを受け、**かつ**代金の全部を払った時」（法37条の2第1項2号）。引渡しだけなら、まだできる。

**1. 規則の全体（法37条の2）**

| 要素 | 内容 |
|---|---|
| 使える人 | 事務所等以外の場所で申込みをした人・契約をした買主（事務所等で申込みをした人は除く） |
| 相手 | 自ら売主の宅建業者（買主も業者なら使えない。法78条2項） |
| やり方 | **書面**で |
| 終わる時① | 書面で告げられた日から数えて8日がたった時（1項1号） |
| 終わる時② | 引渡しを受け、**かつ**代金の全部を払った時（1項2号） |
| 効き目が出る時 | 書面を**出した時**（2項） |
| 効果 | 業者は損害賠償・違約金を請求できない。受け取ったお金を速やかに返す（1項後段・3項） |
| 特約 | 申込んだ人に不利な特約は無効（4項） |

**2. 境界**
- 代金を全部払っただけで、まだ引渡しを受けていなければ、できる（実績 2020-12-39-1、2021-10-39-2）。
- 業者が履行に着手しても終わらない（手付による解除とは別のルール。実績 2020-10-40-イ）。
- 2号の条件は「引渡し」と「代金の全部」だけ。登記の移転は入っていない（条文）。

**3. 次に変えられやすい箇所**
- (a) 「かつ」を「又は」に変える→×（1項2号）
- (a) 告げられていない場合: 8日は数え始まらない。なので、引渡しと代金の全部が済むまではできる。告げる方法は書面を渡すことに限られ、口頭では数え始まらない（規則16条の6）。実績 2021-12-43-1
- (b) 特約: 「引渡しを受けたら終わる」特約は不利なので無効（4項）。逆に「8日を14日に延ばす」のは有利なので有効。実績 2021-12-43-2

**4. 趣旨**　落ち着いていない場所でした申込みを白紙に戻す余地を与える。ただ、お金も物も全部やりとりが済んだ後まで覆せると取引が安定しないので、そこで終わりにする。

**5. ○×**
1. 買主は代金を全部払ったが、まだ引渡しを受けていない（書面で告げられてから8日はたっていない）。クーリング・オフで解除できる。→ **○**（1項2号は両方そろって初めて終わる）
2. クーリング・オフについて告げられていない買主は、引渡しを受けて代金を全部払った後でも解除できる。→ **×**（2号は告げられたかどうかを問わない）
3. 業者が口頭でクーリング・オフについて告げた日から8日がたつと、買主は解除できなくなる。→ **×**（書面を渡して告げなければ数え始まらない。規則16条の6、1項1号）

## 肢2 ×

**0. 判定と決め手**　業者どうしの取引には、法37条の2は使われない（法78条2項）。告げられたかどうかや8日に関係なく、クーリング・オフはできない。

**1. 規則の全体（法78条2項）**

| 要素 | 内容 |

| 使われない規定 | 法33条の2（自分のものでない物件の売買の制限）、37条の2（クーリング・オフ）、38条（損害賠償額の予定などの制限）、39条（手付の額などの制限）、40条（契約不適合の責任の特約の制限）、41条・41条の2（手付金等の保全）、42条（割賦販売の解除の制限）、43条（所有権留保などの禁止） |

**2. 境界**

- 業者が媒介や代理をするだけの取引も、自ら売主ではないので対象外。

**3. 次に変えられやすい箇所**

**4. 趣旨**　8種制限は、プロの業者と一般の人との力の差を埋めるためのもの。業者どうしなら自分で身を守れるので、使わない。

**5. ○×**

2. 業者でない個人Cが売主、業者Dが買主の売買で、Dは喫茶店で申込みをした。Dはクーリング・オフができる。→ **×**（自ら売主の業者がいない。法37条の2第1項）
3. 業者が自ら売主、一般の個人が買主の売買で、買主はクーリング・オフの撤回を電子メールですることができる。→ **×**（書面で。法37条の2第1項）

## 肢3 ×

**0. 判定と決め手**　申込みの場所と契約の場所が違う時は、**申込みの場所**で決める。申込みは喫茶店なので、契約を勤務先でしてもクーリング・オフできる。そのうえ、勤務先が「事務所等」になるのは**買主が自分から申し出た**場合だけ（規則16条の5第2号）。本肢は売主から申し出ている。

レトスとの違い: レトスは「申込みの場所＝勤務先」と読んでいるが、問題文の前提では申込みは喫茶店でしている。結論（できる＝誤り）は同じ。

**1. 規則の全体（クーリング・オフができない「事務所等」。法37条の2第1項、規則16条の5）**

| 場所 | 根拠 |
|---|---|
| 売主業者の事務所 | 法37条の2第1項 |
| 事務所以外の継続的な施設（専任宅建士を置くべきもの） | 規則16条の5第1号イ |
| 一団の分譲の案内所（**土地に定着する建物の中**のものに限る） | 同ロ |
| 売主が代理・媒介を頼んだ他の業者の事務所など | 同ハ |
| 頼まれた業者が設けた一団の分譲の案内所 | 同ニ |
| 説明をした後に、土地に定着する建物の中で開く展示会など | 同ホ |
| **買主が自分から申し出た**自宅・勤務先 | 同2号 |

**2. 境界**

**5. ○×**
1. 買主が自分から申し出て、自宅近くの喫茶店で申込みをした。クーリング・オフはできない。→ **×**（喫茶店は規則16条の5の場所に入らない）
2. 売主業者の事務所で申込みをし、その後に買主の自宅で契約した。クーリング・オフはできない。→ **○**（法37条の2第1項かっこ書）
