## r6-12 定期建物賃貸借（契約①）と普通建物賃貸借（契約②）（正しいもの → 正解 3）

### 肢1 ×

**0. 判定と決め手**　誤り。建物の賃貸借は、登記がなくても**引渡し**があれば、その後の物権取得者（新所有者C）に効力を生じる（借31条）。定期でも普通でも同じ。

**1. 規則の全体（借31条＋民605条の2）**

| 要素 | 内容 |
|---|---|
| 主体 | 建物の賃借人（定期・普通を問わない） |
| 相手 | 引渡しの**後に**その建物の物権を取得した者（譲受人・抵当権者など） |
| 要件 | 建物の引渡し（賃借権の登記でもよい。民605条） |
| 効果 | 賃貸借を対抗できる。賃貸人の地位は譲受人に移る（民605条の2第1項） |
| 譲受人側の要件 | 賃貸人の地位の移転を賃借人に主張（賃料請求など）するには所有権移転登記が要る（民605条の2第3項） |
| 性質 | 強行規定。31条に反する賃借人に不利な特約は無効（借37条） |

**2. 境界**
- 一時使用目的の建物賃貸借には借地借家法が適用されない（借40条）→ 引渡しでは対抗できず、登記が要る（民605条）。
- 抵当権設定登記の**後に**引渡しを受けた賃借人は、競売の買受人に対抗できない。競売手続開始前から使っていれば、買受けから6か月だけ明渡しが猶予される（民395条1項）。
- 借地の対抗要件は「土地の引渡し」ではなく、借地上の自己名義の登記ある建物（借10条1項）。建物と取り違えない。

**3. 次に変えられやすい箇所**
- (b) 「登記しなければ対抗できない」とする特約を有効と書き換える → 無効（借37条。tags 2015-12-1）。
- (a) 譲受人は登記なしで賃料を請求できる、に変える → できない（民605条の2第3項。tags 2012-6-2）。
- (c) 敷金返還債務は譲受人が引き継ぐ（民605条の2第4項）。
- (e) 二重に貸した場合は、契約の先後でなく引渡しの先後（tags 2015-11-3）。

**4. 趣旨**　賃貸人は通常、賃借権の登記に協力しない。そこで、外から見える「住んでいる・使っている」という事実で借家人を守る。

**5. ○×**
- Q1 一時使用目的の建物賃貸借の賃借人も、引渡しを受けていれば新所有者に対抗できる。→ **×**（借40条で借31条は適用されない）
- Q2 賃貸中の建物の譲受人は、所有権移転登記をしなくても賃借人に賃料を請求できる。→ **×**（民605条の2第3項）
- Q3 定期建物賃貸借であれば、「賃借権は登記しなければ第三者に対抗できない」とする特約は有効である。→ **×**（借37条。定期・普通を問わない）

### 肢2 ×

**0. 判定と決め手**　誤り。定期建物賃貸借で**借賃の改定に係る特約**があれば32条は適用されない（借38条9項）→ 契約①では減額請求できない。普通建物賃貸借（契約②）では、減額しない特約は無効なので減額請求できる（借32条1項「契約の条件にかかわらず」）。

**1. 規則の全体（借32条）**

| 要素 | 内容 |
|---|---|
| 主体 | 当事者双方（賃貸人は増額、賃借人は減額） |
| 要件 | 租税等の負担の増減、土地建物の価格の変動その他の経済事情の変動、近傍同種の建物の借賃との比較で**不相当**になった |
| 効果 | **将来に向かって**増減を請求できる |
| 特約（普通借家） | 「一定期間**増額しない**」特約は有効（1項但書）。減額しない特約は無効 |
| 特約（定期借家） | 借賃の改定に係る特約があれば32条を適用しない（借38条9項）→ 減額しない特約も有効 |
| 協議が調わない時 | 増額を求められた側は、裁判確定まで相当と認める額を払えばよい。不足分は年1割の利息を付けて払う（2項）。減額を求められた側は相当と認める額を請求でき、取り過ぎ分は年1割の利息を付けて返す（3項） |

**2. 境界**
- 定期借家でも、改定の特約が**ない**なら32条で増減額を請求できる（tags 2012-12-2・2020-10-12-2）。
- サブリース契約にも32条1項は適用される（最判平成15年10月21日。裁判所サイトの裁判要旨で確認）。

**3. 次に変えられやすい箇所**
- (b) 普通借家の不増額特約（有効）と不減額特約（無効）の入れ替え（tags 2015-12-2・2023-12-2）。
- (a) 協議が調わない時の「相当と認める額」と年1割の利息の向き（32条2・3項）。
- (d) 定期借家の例外（38条9項）には「改定の特約がある場合」という条件が付く。

**4. 趣旨**　長い契約では賃料が相場から外れていくので、当事者に直す手段を与える。賃借人を守る法なので、賃借人に有利な「増額しない」特約だけを認める。定期借家は期間を区切った取引なので、賃料を固定する合意も認めた。

**5. ○×**
- Q1 普通建物賃貸借で一定期間賃料を増額しない特約があれば、その期間中、賃貸人は増額請求できない。→ **○**（借32条1項但書）
- Q2 定期建物賃貸借で借賃の改定に係る特約がない場合でも、賃借人は32条の減額請求ができない。→ **×**（特約がなければ32条が適用される。借38条9項）

### 肢3 ○（本問の答え）

**0. 判定と決め手**　正しい。居住用建物の賃借人が**相続人なしに**死亡し、事実上の夫婦・養親子と同様の**同居者**がいれば、その同居者が権利義務を承継する（借36条1項）。定期か普通かを問わない。

**1. 規則の全体（借36条）**

| 要素 | 内容 |
|---|---|
| 対象 | **居住用**の建物の賃貸借（定期・普通とも。一時使用は借40条で対象外） |
| 要件 | ① 賃借人が**相続人なしに**死亡 ② 婚姻・縁組の届出はないが**事実上夫婦又は養親子**と同様の関係 ③ **同居者** |

| 場面 | 抵当権設定の**後に**抵当地に建物が建てられた |
| 効果 | 抵当権者は、土地と一緒にその建物も競売**できる**（義務ではない） |
| 優先弁済 | **土地の代価についてだけ**（1項但書） |
| 例外 | 建物の所有者が、抵当権者に対抗できる土地の占有権原を持つ場合は一括競売できない（2項） |

**2. 境界**
- 抵当権者が建物の築造を承認していても成立しない（上の最判昭和36年2月10日）。
- 建物がある土地に抵当権を設定し、その後建物を建て替えた場合（土地だけの抵当権）は、旧建物を基準に成立しうる（判例。大判昭和10年8月10日とされるが原文未確認）。共同抵当の場合は肢3。

**3. 次に変えられやすい箇所**
- (a) 一括競売を「しなければならない」に変える（tags 2022-4-3）。
- (a) 優先弁済を「建物の代価からも」に変える（tags 2015-6-4）。
- (d) 389条2項の例外（抵当権者に対抗できる権原がある建物）。

**4. 趣旨**　更地として高く評価して貸した抵当権者に、後から地上権の負担を押しつけると担保価値が下がる。一方で建物を壊させるのも無駄なので、一括競売という手段を与えている。

**5. ○×**
- Q1 更地に抵当権を設定した後、抵当権者の承諾を得て建物を建てた場合は、法定地上権が成立する。→ **×**（最判昭和36年2月10日）
- Q2 一括競売をした抵当権者は、建物の代価からも優先して弁済を受けられる。→ **×**（土地の代価だけ。民389条1項但書）
- Q3 抵当権設定後に建てられた建物は、土地とともに必ず競売しなければならない。→ **×**（「できる」。民389条1項）

### 肢3 ○

**0. 判定と決め手**　正しい。土地と建物に共同抵当権を設定した後に建物を取り壊して再築した場合、新しい建物に法定地上権は原則として成立しない。例外は、新建物の所有者が土地の所有者と同じで、新建物の建築時点での土地の抵当権者が新建物にも土地と**同順位**の共同抵当権の設定を受けたなどの特段の事情がある場合（最判平成9年2月14日 民集51巻2号375頁。判例解説で確認）。本肢は新建物に抵当権を設定していないので不成立。

**1. 規則の全体**

| 要素 | 内容 |
|---|---|
| 場面 | 土地・建物の**共同抵当** → 建物の取壊し → 再築 |
| 原則 | 新建物に法定地上権は成立しない |
| 例外 | 新建物の所有者＝土地所有者、かつ新建物に土地抵当権と同順位の共同抵当権が設定された等の特段の事情 |

**2. 境界**
- 土地**だけ**の抵当権で建物を再築した場合は、旧建物を基準に成立しうる（肢2の境界。原文未確認）。共同抵当かどうかで結論が分かれる。

**3. 次に変えられやすい箇所**
- (d) 例外の例外: 新建物に**同順位**の共同抵当権を設定した → 成立しうる。
- (e) tags 2018-6-3 と同じ論点。

**4. 趣旨**　共同抵当権者は、土地と建物を合わせた全体の価値を押さえている。建物が壊されたら更地の価値を期待するのが当然で、新建物に地上権を認めると担保価値が不当に下がる。

**5. ○×**
- Q1 共同抵当の建物を再築し、新建物に土地の抵当権と同順位の共同抵当権が設定された場合は、法定地上権が成立しうる。→ **○**（最判平成9年2月14日）
- Q2 土地と建物の共同抵当では、建物を再築すると、どんな場合も新建物に法定地上権は成立しない。→ **×**（特段の事情があれば成立。同判例）

### 肢4 ○

**0. 判定と決め手**　正しい。抵当権設定時に土地・建物ともAの所有なので要件を満たす。その後に建物をDに譲渡しても、実行されれば乙建物のために法定地上権が成立する（大連判大正12年12月14日。判例解説で確認）。

**1. 規則の全体**　共通表の「判断は**抵当権設定時**」。設定後の譲渡は成否に影響しない。

**2. 境界**
- 抵当権設定時に同一所有なら、設定後に**土地**の側を譲渡した場合も同じ考え方（民388条の要件は設定時で判断）。
- 基準は「実行時」ではなく「設定時」。実行時に同じ所有者かどうかは関係ない。

**3. 次に変えられやすい箇所**
- (e) tags 2016-4-1・2018-6-4 で同じ論点。
- (d) 1番抵当権と2番抵当権で基準時が分かれる場合（肢1の3. 参照）。

**4. 趣旨**　抵当権者は設定時の状態（建物が建っている土地）で評価している。その後所有者が誰に変わっても、評価の前提は変わらない。

**5. ○×**
- Q1 法定地上権の成否は、抵当権の実行時に土地と建物が同じ所有者かどうかで判断する。→ **×**（設定時。民388条、大連判大正12年12月14日）
- Q2 土地と建物が同じ所有者の時に土地に抵当権を設定し、その後に土地を第三者に譲渡した場合も、実行されれば法定地上権は成立しうる。→ **○**（設定時に同一所有。民388条）
