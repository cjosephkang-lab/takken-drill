# 学習の積み上げ（study-story）

「これまで何をやってきたか」を、Firestore の実際の解答履歴から機械的に集計した
もの。合格発表のタイミングで動画・記事に束ねるための素材。

## 撮影が要らない素材である

きじーさんの助言（2026-09-09）は「発信は合格してから。過程は残しておく」だった。
その「過程」のうち、**数字で語れる部分はすでに全部残っている**。画面録画のように
撮り逃すことがなく、後から遡って作れる。だから最初にこれを作る。

## 使い方

```bash
python3 scripts/study-story.py            # docs/study-story/YYYY-MM-DD.md に書く
python3 scripts/study-story.py --stdout   # 標準出力だけ
```

`gcloud auth login` が済んでいることが前提。日次の自動実行には入れていない
（毎日更新するものではなく、発信の直前に最新版を作れば足りる）。

## 数字の出どころ

すべて `scripts/study-story.py` の中で計算しており、途中式がレポートに残る
（暗算した数字を答えに書かない・グローバル規約 2026-08-25）。

| 数字 | 出どころ |
|---|---|
| 日ごとの解答数・正解数 | Firestore `progress/{uid}` の `dailyLog` |
| 科目別の着手・習得 | 同 `answers`（`streak` が3以上で習得） |
| メモ件数 | 同 `notes` |
| 収録問題数・科目 | `src/data/questions.ts` |
| 試験日 | `scripts/study-story.py` の `EXAM_DATE`（App.tsx と揃える） |

## 事実だけを出す（解釈を混ぜない）

このレポートは**解釈を書かない**。実データは綺麗な上昇曲線ではないため、
「右肩上がりに伸びた」と書くと事実と違うものになる。実際、2026-09-09 時点で
8月下旬に正答率0%の日が5日並び、直近も58%→81%→74%と振れている。

代わりに、データが実際に語っていることを出す。9月5日を境に1日あたりの問題数が
5.2問から29.0問に変わっており、これは「じわじわ上達した話」ではなく
「途中で本気を出した話」である。均さず、1問だけの日も0%の日もそのまま載せる。

発信の文面を作るのは skill `study-log-broadcast` の役割で、このフォルダは
その入力になる事実を置く場所。
