# 新しい形の解説の試作と評価（2026-10-27）

問い: 過去問にどういう解説をつければ、その過去問を解くことで令和8年度の問題を解けるようになるか。

## やり方（後知恵を避けるため）

1. 令和8年度に落とした問題に近い過去問のうち、10年分のドリルにある7問を選んだ（令和3年12月問20、令和6年問12・問27、令和5年問32、令和3年10月問9、平成30年問6、令和4年問38）。
2. 解説を書く前に、各過去問について「令和8年度の決め手」と「本人の誤解の箇所」を判定基準として固定した（[grading_criteria.md](../kaisetsu-proto/grading_criteria.md)、16:40作成）。
3. 解説は、令和8年度の問題・講評・振り返り資料を見ることを禁じた別の担当（2本）に書かせた。令和8年度の試験（2026年10月）は書き手のAIの学習データの期間より後なので、学習データからの混入もない。形は、各肢に「判定と決め手」「規則の全体（要素の表）」「境界」「次に変えられやすい箇所（根拠の条番号つき）」「趣旨1行」「○×2〜3問」。条文は e-Gov（2027年4月1日時点）で確認。
4. できた解説（[kenri.md](../kaisetsu-proto/kenri.md)、[gyoho.md](../kaisetsu-proto/gyoho.md)）と今あるレトスの無料の解説を、同じ基準で判定した。「入っている」は、その規則が正誤を判断できる形で書かれていること。

## 落とした18問との対応

確かめたのは「落とした問題に合わせて選んだ過去問の解説に、決め手の規則が書かれているか」までで、本人が本番の問題を正解できるようになるか、まだ見ていない年度に効くかは確かめていない。

- 決め手の規則が書かれていた: 問4・20・30・41・42 の5問。一部: 問9・12。
- 未検証（近い過去問の解説を試作していない）: 問7・8・15・17・18・23・32・43。このうち問18・23・32は論点がめったに出ないので、届かない可能性が高い。
- 解説では防げない側: 問28・33・48（違和感で切れない・見落とし・丸の付け間違い。解き方の手順で対処する）。

仮に5問すべてを本番で取れていたら37点になるが、これは得点が上がることの実証ではない。「解説に書いてあった」ことと「読んで身についた」ことは別で、後者は確かめていない。読み返しは学習の効果が低い方法なので、境界と「次に変えられやすい箇所」を○×や書き出しにして思い出す練習で使うのが前提になる。
