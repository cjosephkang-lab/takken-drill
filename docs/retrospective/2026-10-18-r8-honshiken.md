- **連れ子の観点が抜けた理由**: 試験当日の朝、法定相続分（子・親・兄弟姉妹）と非嫡出子の扱いをAIで集中的に練習したが、「再婚相手の連れ子」という観点は出てこなかった。練習していたのは「相続分の数字」で、抜けていたのは「誰が子に当たるか」という相続人の範囲の境界（実子・養子・非嫡出子・連れ子・内縁の配偶者・胎児）だった。
- **過去問の選び方の穴**: 令和3年は試験が10月と12月の2回あり、ドリルの5年分には12月試験を入れていた。ところが10月試験の問9（[宅建レトス](https://takken-success.info/2021-10kakomon/r031-9/)）は、「妻の亡夫との子（連れ子）は相続人にならない」という今年の問4とほぼ同じ形の問題だった。令和3年10月を入れていれば、連れ子の観点に一度は触れていた。
- **AIでの掘り下げ方**: 「法定相続分を練習させて」ではなく、「この論点で、試験が引っかけに使う『似ているが扱いが違う』ケースを全部挙げて、根拠条文つきで○×にして」と頼む。深さの目安は、どの論点でも「結論・誰に当てはまるか（範囲）・例外・似た制度との違い」の4つまで。出題実績のない判例の細部は追わない。
- **講義動画は必須**: 今年は無料の範囲の動画（全体把握用）にとどめた。テーマごとの細かい動画は有料のメンバーシップにあったが、使わなかった。過去問から離れて、細かい論点を網羅する入口がなかった。
- **一問一答が効いた理由**: 4択は「この選択肢が正解だった」という覚え方で解けてしまう。一問一答は、知っているか知らないかだけが試される。来年は、毎日の練習の中心を一問一答にし、4択は本番形式の確認と模試に使う。
- **同じ選択肢が年をまたいで繰り返し出る**: 100〜200肢のうち3〜4肢は、過去と完全に同じ選択肢だった。繰り返し出た選択肢は出題者が好む引っかけなので、一問一答にするとき、出題回数で重みを付ける。施工管理技士の試験にも使える可能性がある。
- **定着の物差しの作り直し**: 今年の定着率は「過去5年分の問題に対する直近の正答率・連続正解回数」だった。来年は「論点の網羅率（過去10〜15年で出た論点のうち、練習した割合）×論点ごとの定着率（間隔を空けて解き直したときの正答率）」にする。たとえば「宅建業法は5年分では論点の60%しか覆えていないので、残り40%はこの年度のこの問題で埋める」と分かるようにする。過去15年分を論点に分け、各年の論点のうち直前5年・10年に出ていた割合を測る調査を、この物差しの土台にする（未実施）。
- **学習時間の実感**: アプリの記録から推定した約48時間に、動画などを足して、全体で約100時間という感覚。

### 過去問の網羅率の調査（2026-10-19）

宅建レトスから2011〜2025年の17回分（847問。2014・2015・2019年の問48の統計は未掲載）を取得し、令和8年（問題用紙の写真から）と合わせた3,556の選択肢に、AIが論点を付けた。さらにAIが、同じ規則を指すものを1,833の「規則クラスター」に束ねた。試験Eの「直前N年の網羅率」は、Eの選択肢のうち、同じ規則がE以前かつ実施年がE−N以上の試験に出ていた割合。作業データは scratchpad（`coverage/`）にあり、リポジトリには入れていない（レトスの本文を含むため）。

**他の年でも、直前5年→10年の伸び（選択肢単位で+9〜21ポイント）に比べ、10年より先の伸び（+0〜7ポイント）は小さかった**（2021年10月〜令和8年の7回。古い年ほど「10年より先」の期間が短く、条件はそろっていない）。どこまで広げるべきかは、追加の学習時間との兼ね合いでも決まるので、この数字だけで最適な年数は決められない。

**仮説の判定:**

- 「過去問だけでは限界がある」: おおむね支持。令和8年の34%（17問）は、2011〜2025年の過去問の中に同じ規則がなかった。ただし、落とした問題のうち同じ規則がなかった9問（問7・8・9・12・17・23・28・33・43）を本人の理由で見ると、問33は知っていた規則の見落とし、問28は違和感から解けた問題、問9・12・17は結論までは知っていて要件や聞かれ方で落とした問題で、過去問にないから取れなかったとは言えない（2026-10-23 追記）。
- 「10年分なら取れた」: 一部支持。覆える問題は19問→32問に増えるが、落とした問題で増えるのは3問。
- 「同じ選択肢が繰り返し出る」: 支持。特に宅建業法で繰り返しが多い。
- 「定着の物差しが甘かった」: 支持。ドリルにあった6問を落としており、今年の物差しはこれを弱点として拾えていなかった。
- 「一問一答が効く」: 今回のデータでは比べる件数が足りず、検証できない。

**この数字の限界（codexの指摘を反映）:**

1. 論点の付け方と束ね方はAIの判断で、人が全件を検証していない。誤った統合・分割や、法改正の扱いで網羅率は数ポイント変わりうる。レトスは古い問題を今の法律に合わせて書き換えているので、網羅率は「今の法律で同じ規則か」で数えている。
2. 問題単位の判定は正解の肢だけで見ているので、消去法で解ける場合を考えていない。4択と個数・組合せ問題で基準も違う。
3. 「15年分の中に同じ規則がない」は、この期間と分類基準での未収録率で、本当の新論点の割合とは限らない（2010年以前に出ていた可能性がある）。
4. 落とした18問の分類は「過去問にあったかどうか」の分類で、失点の原因そのものではない。既出の問題でも、未学習・読み違いなどで落とすことはある。

## 論点体系の方針（2026-10-18 決定事項の案）

過去問だけでは範囲が足りず、条文をそのまま全部やると出ない論点まで深掘りして遠回りになる。そこで、範囲と深さを別のもので決める。

| 決めること | 何で決めるか | やり方 |
|---|---|---|
| どの論点をやるか（範囲） | 過去問の出題実績（10〜20年分）、最近の法改正、予備校の講評で「手薄な内容」とされた論点 | 出題実績のない条文は原則やらない（法改正で新しくできた論点は例外として入れる）。論点ごとに「出題率（何年に1回出るか）×1点」で期待得点を出し、期待得点の高い順に並べる。分野ごとに、期待得点の合計が目標点（権利関係8点、宅建業法18点など）を2点ほど上回るところまでやる |
| 論点の中で何を覚えるか（深さ） | 過去問の誤りの選択肢で、実際に変えられてきた部分 | 誤りの選択肢の多くは、条文の数字・主体・対象・例外のどこかを変えて作られている（全部ではない。複数か所を変えた肢や、事例への当てはめを問う肢もある）。変えられた箇所ごとに○×を作り、事例への当てはめは事例問題で別に練習する |
| 答えの正しさ | 条文（e-Gov）と国交省の「解釈・運用の考え方」 | ○×の解説に条文番号を付け、AIの解説はこれと照らして確かめる |

商品化する場合も、範囲の判定に使うのは「どの論点が何回出たか」という事実だけで、過去問の文章は載せない。過去問の文章を商用で使ってよいかは未確認なので、確かめるまでは載せない。法令と国の通達は著作権の対象外（著作権法13条）。

### この方針で何が解決するか

| 今回の課題 | 解決するか | 理由・追加で必要なもの |
|---|---|---|
| 過去問にない論点が出た（問32・43、問8の合意解除など） | 大部分は解決する | 出題実績を10〜20年に広げ、法改正も入れる。ただし、その年に初めて出る論点は拾えない（今年のユーキャン講評でも問15・17・32は「一般的な学習範囲を超える」「手薄な内容」とされた）。初出の論点は、合格点の計算では捨て問として扱う |
| 要件・対象・主体・例外の抜け（失点の中心） | 解決する（作り方しだい） | 「変えられた箇所」ごとに○×を作れば、抜けた部分そのものを練習できる。結論だけの○×では解決しない |
| 似た概念の混同（連れ子と非嫡出子、特別用途地区と特定用途誘導地区） | 解決する（作り方しだい） | 似た制度を並べた比較の○×を、意識して作る |
| 定着しているかどうか分からない | 一部解決 | 論点ごとに「間隔を空けて解き直したときの正答率」で測るよう、集計も直す |
| AI解説のハルシネーション | かなり減る | 根拠の条文を一緒に渡して確かめる。ゼロにはならない |
| 制度の仕組みの理解（代理とは何か） | 解決しない | 論点ごとに「この制度は何のためにあるか」の短い説明か図を別に用意する |
| 見落とし・正誤の取り違え（問33・48） | 解決しない | 下の「本番の解き方の手順」で対処する |
| 学習時間の不足 | 解決しない | 時間の確保は別に計画する |

## 本番の解き方の手順

今回の見落とし（問33・48）、違和感で切れなかった問題（問28）、主体の確認漏れ（問42）を防ぐための手順。来年の模試で毎回この手順で解き、身につける。

1. **問題文の「正しいもの／誤っているもの」「いくつあるか」に印をつけてから、選択肢を読む。** 問48は、正しいものを選ぶ問題で誤りの選択肢に丸をつけた。
2. **事例問題は、最初に主体を書き出す。** 売主・買主・媒介業者のそれぞれが宅建業者かどうかを、問題用紙の余白に書く。問42は、売主が業者でないことに気づけば解けた。
3. **数字に違和感があったら、それをきっかけに根拠を思い出す。** 違和感だけで正誤を決めない（正しい肢を切る危険がある）。問28の「実務経験5年」は、違和感をきっかけに「登録は2年」を思い出せれば解けた。
4. **個数問題と組合せ問題は、各選択肢の○×を余白に書いてから数える。** 見直しのときは、その○×の根拠を一言で言えるかを確かめる。
