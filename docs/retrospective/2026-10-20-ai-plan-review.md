# AIの計画・指示の検証と、直前の勉強の効果（2026-10-20）

令和8年度本試験（32点。権利関係9/14、法令上の制限4/8、税・価格2/3、宅建業法13/20、免除科目4/5）を物差しにして、(1) 直前に足した教材・機能がどれだけ効いたか、(2) Claude と毎朝のコーチが出した計画・指示を本人がどこまで実行し、その計画が妥当だったかを検証した。材料は git log、docs/coach・docs/study-log、9/9以降の Claude との会話記録（それ以前は残っていない）。調査はサブエージェント2本、数字はスクリプトで計算（[analysis/](analysis/) に保存）。codex の指摘5点を反映済み。

## 1. 直前の勉強と追加機能の効果

10/12〜試験当日朝に、○×381問・数字シート159項目・統計7項目を追加した。うち10/17午後〜10/18朝だけで約540項目。

- **直前の項目があった問題の正答率は、なかった問題より高かった。** 仮定を置いて点数に直すと中心で+3.4点（1標準誤差 ±2.8点、95%の幅 −2〜+9点）。ただしこれは関連で、因果ではない。直前の項目があった問題となかった問題で、難しさや既習度が違う可能性も除けていない。
- **実際に解いたかの確認（2026-10-21、認証の復旧後に Firestore の解答記録で確認）**: 直前の項目が決め手を直接覆っていた14問のうち、11問は、その○×を試験開始（10/18 13:00）より前に解いていた（本番の正解は8/11）。解いていなかったのは問26だけで、本番は正解だった。残る問16・22は数字シートだけが覆っており、数字シートの記録は項目単位で突き合わせられない。ただし問22の枠の数字は1項目も解いておらず、それでも正解していた。解いていたのに落とした3問は、問4（連れ子）、問20（借家人）、問48（丸の付け間違い）。このうち問4と問20は、○×が境界を教えていなかった問題。「直前の項目は解かれていなかった」という説明は成り立たない。
- **効いた可能性が高いもの**: 法令（問11〜24）の数字と業法の手続きの○×。直前の項目が決め手を覆っていた問題は15/19正解、覆っていない問題は17/31。直前の項目がなければ落としていた可能性が比較的高いのは、問5・13・16・21・24。
- **効かなかったと見られるもの**: 原則だけを教えて、境界・例外を教えなかった○×。連れ子（問4）、1番抵当が基準（問9）、借家人は組合員でない（問20）、二重供託の取戻しは公告不要（問30）。問9・15・20では、○×が教えていた内容と逆の肢を選んでいる。
- **同じ規則を解き直すと効き、論点が同じだけでは効かない**。10/12〜17に同じ規則を解き直した問題は8/12正解、論点だけ同じ問題は10/18（56%）で、対応のない問題（14/20、70%）より低かった。
- **配分が後ろに偏った**。10/13〜16は1日3〜21問で、約540項目を試験前の約24時間に詰め込んだ。

## 2. 計画・指示の実行と妥当性

| 計画・指示 | 実行 | 妥当性（本番から見て） |
|---|---|---|
| 予想点＝科目の正答率×配点、38点以上で「安全圏」（7/21設計、9/8〜当日まで毎朝表示） | 本人は途中から見なくなった | **誤り（根本原因）**。最後の1回の正誤で数えたため水増し。当日の予想48.3点に対し本番32点。反証（9/6の初見模試29点、10/4の業法初見45%）がそろっていたのに、判定式は当日まで変わらなかった |
| 業法18点・権利8点の目標配分 | 学習順は実行 | 権利8点は妥当（本番9点）。業法18点は、10/4に初見45%と分かった後も見直さなかった |
| 過去問を令和3年12月〜令和7年の5年分に限る | 実行（241/242問に着手） | 一部誤り。令和3年10月を外したため連れ子の問題に触れなかった。10/12の「5年分で妥当」は、選択肢単位で61%が初出という自分の数字と食い違っていた |

| 模試は1〜3回、令和5年度を温存 | 9/6の1回だけ（29点）。温存した年度も崩れた | 考え方は妥当、運用は誤り。9/6の29点が本番に最も近い予測だったのに、予想点の根拠にしなかった。10/4は本人が形式を断り、Claude も同意して取りやめた |
| 9/13「業法・権利の31.8点は信頼できる」 | ― | 誤り。根拠は繰り返し後の正答率94%・93% |
| 9/26「33点を割っている可能性」、10/8「31.8点」、10/12「24.5〜33.3点」 | ― | 方向は正しかった（本番32点）。ただし幅が広く、予測の精度としては限定的。しかもコーチの表示は直さなかった |
| 10/4「残りに要る学習時間は20.8時間」 | 1日の量はほぼ実行 | 立て方が誤り。アプリの残り作業量を測っただけで、合格に要る時間（200〜500時間）と比べていない |

**切り分け**: 予想点と安全圏、学習量の物差し、範囲と深さ（5年分・問題単位）、一問一答を整えた時期の遅さは、**計画（AI）の問題**。9月中旬〜下旬の停滞と模試の不足は**両方の問題**。本人の実行が止まった一方で、計画の量が非現実的で、コーチは止まっていて、模試の取りやめにはAIも同意した。

## 3. Claude が本来すべきだった助言（自己検証）

1. **水増しを見つけた日に、コーチの判定を自分で直す。** 9/9に「予想38.8点は信用しないで」と言い、9/26・10/3にも指摘したが、毎回「直しますか」で止め、10/17には「試験後に」と先送りした。takken-drill は自動コミット・デプロイの許可がある範囲で、直す権限はあった。会話をまたいだ記憶がないため、誤った数字が後の会話の助言（10/7・10/17）を汚した。正しい数字は会話ではなく、仕組みの側に残すべきだった。
2. **予想の根拠を最初から「初見の正答率と初見の模試」にする。** 9/6の模試29点の時点で、「このままでは33点に届かない」と言うべきだった。
3. **学習量を合格の目安と比べて示す。** 9/5の時点で、1日4.9問・稼働率61%と分かっていた。予備校が示す一般的な目安（200〜500時間）は本人の必要時間そのものではないが、比べる物差しとして示し、「今のペースだと試験までの累計が目安を大きく下回る。時間を増やす計画を一緒に立てる」と判断を求めるべきだった（累計約48時間の推定は、アプリの解答時間の実測34時間と、解説を読む時間の仮定14時間を足したもの）。
4. **範囲と深さを選択肢の規則で設計する。** 過去問は10年分（令和3年10月を含む）を入れる。講義・テキストで論点を網羅し、一問一答は境界・例外・主体を変えた形で、学習の初期から使う。
5. **直前期に道具づくりを止める。** 10/4以降の2週間で27コミット（10/17だけで14件）。本人の作業時間の記録はないので、勉強の時間を奪ったとは断定できないが、追加した○×は前日・当日に集中し、復習の回数が取れなかった。試験2週間前には機能追加を止め、模試と弱点の復習に時間を寄せるよう助言すべきだった。
6. **薄い根拠で結論を戻さない。** 10/17の「業法は8割」は、同じ問題を解き直した正答率で、それまでの慎重な分析を覆していた。
7. **模試は本人が嫌がっても1回は通す。** 「その場で振り返れない」には、模試の後に振り返りの時間を取ることで応えればよかった。
