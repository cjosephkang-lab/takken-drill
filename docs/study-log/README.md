# 学習ログ（study-log）

宅建アプリで書いたメモを、日付ごとに書き出したものを置く場所。

## 何のためのフォルダか

このフォルダは「発信パイプライン」の入り口。アプリで勉強しながら書いた自分メモを、その日の分だけ Markdown にまとめて置いておくと、あとで Claude Code が git のコミット履歴と合わせて読み、X 用・Note 用の発信素材を作れる。

## 毎日やること（これだけ）

1. アプリで勉強し、問題ごとにメモを書く（今まで通り）。
2. その日の終わりに、メモ入力欄の下の **「今日の学習を書き出す」** を押す。
   - Markdown がクリップボードにコピーされ、同時に `takken-drill-studylog-YYYY-MM-DD.md` としてダウンロードされる。
3. その内容を、このフォルダに `YYYY-MM-DD.md`（例: `2026-07-21.md`）という名前で保存する。
   - ダウンロードしたファイルをここに移動してもよいし、コピーした中身を貼り付けてもよい。

この保存の一手間だけが手作業。あとは Claude Code に「今日の発信素材を作って」と言えば、ここのファイルと git ログを読んで素材を生成する。

## ファイル名の決まり

- `YYYY-MM-DD.md`（例: `2026-07-21.md`）。1日1ファイル。
- 書き出しの中身は「# 学習ログ 日付」＋「## 分野（和暦 問番号）」の見出しごとのメモ。
