# UIの評価（ui-review）

初見ユーザーから見てアプリがどう見えるかの評価を置く場所。

## なぜこのフォルダがあるか

このアプリは姜さんの学習道具として作られており、姜さん自身は毎日使っているので
何がどこにあるか分かっている。**作った本人と、それを毎日見ている担当（Claude）
には、初見の目が無い。**

きじーさん（カメラマン）が実際に使う約束をしたことで、初見ユーザーが実在する
状態になった。その前に何が分からないかを確かめておく。

## 中身

| ファイル | 中身 |
|---|---|
| `2026-09-10-first-time-user.md` | 情報要素78個のうち初見で分かるのは31個。削る優先順位5件 |

## 評価のやり方

**このリポジトリの文脈を知らない独立した視点に依頼する。** 文脈を知っていると
「これ何」と思えない。判定はスクリーンショットに基づいて行い、コードを読むのは
判定の後にする（コードを読むと意図が分かってしまい、初見の判定にならない）。

撮影は iPhone 縦想定の viewport 390x844。Playwright は devDependency に
入っている（skill `ui-screenshot` 参照）。

## 使うときの原則

**姜さん自身の使い勝手を壊さない。** このアプリは第一に姜さんの学習道具で、
初見への分かりやすさは第二。折りたたみに入れる提案は、1タップで開ける形を保つ。
